# Styled Landing Page

A responsive, professionally styled landing page created as my **second project for the Fullstack Web Development Bootcamp**.

This project focuses on building a complete landing page using semantic HTML5 and modern CSS. It demonstrates page structure, responsive layouts, navigation, typography, the CSS box model, Flexbox, accessible images, and mobile-first design principles.

## Project Overview

The goal of this project was to create a visually appealing landing page that works well across desktop, tablet, and mobile screen sizes while following modern HTML and CSS best practices.

The page includes a professional header and navigation menu, a hero section with a clear call-to-action, multiple content sections, and a footer containing contact information.

## Features

* Semantic HTML5 page structure
* Professional header and navigation menu
* Hero section with headline and call-to-action
* Three or more main content sections
* Footer with contact information
* Internal navigation links
* Responsive layouts for mobile, tablet, and desktop
* Flexbox-based layout components
* CSS box model styling using margin, padding, and borders
* Multiple CSS color formats, including hex, RGB, and named colors
* Styled typography with custom font families, sizes, and weights
* Proper heading hierarchy using `h1`, `h2`, and `h3`
* Images with descriptive `alt` text
* External CSS stylesheet
* Page title and meta description
* HTML and CSS written to pass W3C validation

## Responsive Design

The site includes multiple responsive breakpoints to provide a consistent experience across different viewport sizes:

* **Mobile:** below `768px`
* **Tablet:** `768px` to `1024px`
* **Desktop:** above `1024px`

The mobile layout is designed to remain usable from approximately **350px viewport width and above**, without overlapping elements, cut-off text, or hidden images.
